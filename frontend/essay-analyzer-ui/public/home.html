Handwriting Spell Checker

AI-powered spelling and grammar checker for handwritten Marathi student work in Google Classroom.

About this application

Handwriting Spell Checker is a Google Chrome Extension designed for primary school teachers in India. It uses artificial intelligence to read handwritten Marathi student homework submitted via Google Classroom, identify spelling and grammar errors, and help teachers provide faster and more consistent feedback.

The application integrates directly with Google Classroom. Teachers click a "Check Spelling" button that appears inside Classroom, select a student's submitted handwriting image, and the AI reads the handwriting and identifies errors. Teachers can then review, accept or reject each correction, add notes, and download a printable report card.

Purpose

The single purpose of this application is to check spelling and grammar in handwritten Marathi student work submitted to Google Classroom, using AI to read the handwriting and identify errors for teacher review.

Features

  • AI handwriting recognition (OCR) for Marathi script
  • Spelling and grammar error detection
  • Teacher review workflow — accept or reject each correction
  • Printable report card generation
  • School learning dictionary that improves over time
  • Works directly inside Google Classroom
  • Monthly usage tracking per school

Google API Usage

This application uses the following Google APIs solely to fulfil its single purpose of spell checking handwritten student work:

  • Google Classroom API — to read courses, assignments, and student submissions (read-only)
  • Google Drive API — to download student handwriting image files attached to submissions (read-only)
  • Google Sheets API — to read and write the optional school correction dictionary
  • Google Identity — to authenticate the teacher's Google account

User data is never sold or shared with third parties. Student handwriting images are processed by AI for spell checking only and are never stored on our servers. See our full Privacy Policy.
